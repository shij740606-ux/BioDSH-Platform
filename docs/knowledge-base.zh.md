# BioDSH 知识库

桌面端的“知识库”页使用 RAGFlow 管理 Word、PDF 文档的解析、切片、向量索引和检索。BioDSH 负责保存用户选择、原文件副本、文件夹同步记录，以及把检索到的原文和页码送入当前对话。

## 解析位置

| 选项 | RAGFlow 地址 | 文件与计算位置 | 适用场景 |
| --- | --- | --- | --- |
| 本机解析 | 默认 `http://127.0.0.1:9380`，可修改 | 原文件副本保存在 `~/BioDSH/knowledge/originals/`；RAGFlow 索引和计算位于本机 | 少量文档、离线或数据不离开电脑 |
| 服务器解析 | 用户填写 HTTP/HTTPS 地址 | 本地仍保存原文件副本；文档上传、解析和向量计算由服务器 RAGFlow 完成 | 大 PDF、大批量文档、集中使用 GPU/CPU |

RAGFlow API 密钥保存在系统安全存储中，不写入 `settings.json`。服务地址和解析位置写入设置，发布后可由每个用户自行配置，不依赖固定 IP 或端口。

## 当前流程

1. 在 RAGFlow 中创建 API Key。
2. 在“知识库”页选择“本机解析”或“服务器解析”，填写地址和 API Key 后连接。
3. 建立一个或多个知识库。
4. 单独添加 `.pdf`、`.doc`、`.docx` 文件，或选择需要监控的文件夹。
5. BioDSH 上传新文件并调用 RAGFlow 开始解析；桌面应用运行期间每 60 秒检查一次监控文件夹，也可手动同步。
6. 在页面中输入问题，可先查看命中文件、页码、原文片段和相似度，也可把这些引用送入当前对话。

文件夹同步用相对路径、文件大小和修改时间识别变化。删除监控关系不会删除原文件、RAGFlow 文档或已建立的索引。

## RAGFlow 接口边界

桌面端只依赖 RAGFlow 的公开 HTTP API：知识库列表与创建、文档上传与解析、文档状态和检索。部署时只需保证桌面电脑能访问配置的 RAGFlow 地址；远程服务应通过 HTTPS 或可信内网提供，不需要把 RAGFlow 数据库端口暴露给桌面端。

本阶段不包含共享知识库、项目级权限和文档版本历史。这些能力后续复用 BioDSH 已有的用户、项目和角色权限模型接入。
