# 桌面 SSH 服务器管理

“服务器管理”是用户个人的 SSH 主机列表，可直接连接已有 Linux 服务器，无需先注册平台 Worker。

## 使用流程

1. 点击左侧“服务器管理”，添加自定义名字、IP/主机名、SSH 端口、用户名。
2. 选择密码认证或私钥认证。私钥可粘贴或从文件导入，加密私钥另填口令。
3. 保存后点击“测试连接”，首次连接必须核对并确认 SHA-256 主机指纹。指纹变化不会自动接受。
4. 勾选“允许智能体使用”；可同时勾选多台。点击“在对话中使用所选服务器”，然后描述需要执行的任务。
5. 编辑时密码与私钥不会回显，留空保留已保存的值。更换 IP 或端口会清除主机信任与选中状态，更换用户或认证方式会清除选中状态。

## 数据与工具边界

- `~/BioDSH/ssh/hosts.json` 保存主机元数据、指纹和用户选择，不保存密码、私钥或私钥口令。
- 凭据保存在系统安全存储，较长的私钥分成多个安全条目，避免 Windows Credential Manager 的单条容量限制；不写入明文临时文件。
- 每次启动本机智能体，桌面自动接入内置 `biodsh_ssh` MCP。`list_servers` 返回用户选择的主机；`execute` 只接受选中主机的编号，连接前再次校验主机公钥。
- SSH 运行时是锁定版本的 `ssh2`；本地后端通过子进程标准输入传递凭据，不通过命令行参数、环境变量或模型提示传递。
- 每条命令使用新的 SSH 连接与远程 shell，工作目录需要在命令中显式 `cd`。工具操作有 5–300 秒时限，输出限制为 1 MB。
- 取消勾选阻止后续新连接，不自动终止已启动的远程进程。超时关闭连接，也不保证服务器的后台任务停止。
- 此页面面向当前 Tauri 桌面版及本机运行的智能体；原有“计算服务器”页面继续管理平台 Worker。

## 验证

在 `desktop/` 中运行：

```text
node scripts/stage-ssh.mjs
node resources/ssh/client.test.cjs
cargo test --manifest-path src-tauri/Cargo.toml ssh_hosts --lib
```

检查主机指纹获取、错误指纹拒绝、错误认证拒绝、密码和私钥执行、未选中主机拒绝，以及 Windows 大凭据安全存储往返。

本机程序更新使用 `npm run tauri:build:app`。直接替换程序时还需同步新 `resources/ssh/` 到安装目录的 `ssh/`；正式安装包自动包含此资源。
